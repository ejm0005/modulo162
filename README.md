Reflexión:
Esta práctica me ha servido para ver cómo se trabaja en el mundo real del testing. Usar Selenium con JUnit te da muchas posibilidades, y aunque al principio cuesta pelearse con los selectores, una vez que tienes la estructura montada, añadir nuevas funcionalidades es rápido y sencillo. Destaco esto porque lo que más me ha quedado claro con esta tarea es que automatizar no es solo hacer scripts que pulsen botones, sino saber organizar el código para que no sea un caos, lo que me parece una base fundamental para cualquier desarrollador hoy en día.
